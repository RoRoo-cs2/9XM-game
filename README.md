
# 🎮 9XM - 3D Coin Collection and Survival Game

## 📌 About the Game
9XM is a 3D game developed using Unreal Engine. The player's objective is to collect coins while avoiding enemies and survive for as long as possible.

## 🎯 Objectives
- Collect as many coins as possible.
- Avoid enemies and dangerous encounters.
- Survive for as long as possible.

## ✨ Features
- 3D gameplay environment
- Coin collection mechanics
- Enemy avoidance and survival gameplay
- Interactive player movement

## 🛠️ Technologies Used
- Unreal Engine
- Blueprints / C++ (depending on implementation)

2. Move around the environment.
